本地文件

和本页同目录

浏览器不许网页「不问自取」地写本地文件，所以第一次要你点一下授权。 绑定之后：每次改动都会写进 taphabit-data.json（就在 html/ 里）， 同时另存一份到 IndexedDB。容量按磁盘走 —— 这就是「存储无限制」的那一半， 另一半是小程序那边 95% 会自动清理，这边不会。

导入 / 导出

JSON 结构和小程序完全一致

文件格式和小程序的「存储管理 → 导出」一模一样（habits / records / settings）。 「复制 JSON」拿到的文本可以直接粘进小程序的导入框；反过来，小程序导出的内容也能在这里导入。 导入会**整份覆盖**当前数据，导之前先备份。
